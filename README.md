# CodeChallenge - Java Unit Test

This project serves as an initial intro to unit testing. It contains a simple class, interface and test file.

Required unit test libraries must be imported into the project. 

All "TODO" items located in the source code files must be completed. 

    * Complete each method in the class to be tested.
    * Build at least 1 additional test case per method in the test file.
    * Change the last 3 test cases based on the specific implementations created.


Required libraries:
JUnit
